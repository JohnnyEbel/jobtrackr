# JobTrackr

A cloud-native job tracking application deployed on AWS using Terraform and Docker.

## Architecture Goals

- Infrastructure as Code (Terraform)
- Immutable-style deployments
- CI/CD via GitHub Actions
- Production-style AWS setup (VPC, ALB, EC2, IAM)
- Free-tier compatible

## Tech Stack

- Python (Flask)
- SQLite
- Docker
- AWS (EC2, ALB, IAM, CloudWatch)
- Terraform
- GitHub Actions
