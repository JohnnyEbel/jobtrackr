1️⃣ Commit-Message-Konvention (Conventional Commits)

Warum wichtig?
    Saubere Historie
    Nachvollziehbare Änderungen
    Automatisierbare Releases
    Wirkt extrem professionell


📌 Grundstruktur
"type(scope): short description"

Beispiel:

"feat(api): add POST /jobs endpoint"
"fix(docker): correct port mapping"
"docs(readme): add architecture overview"
"refactor(db): extract database initialization"


🔑 Die wichtigsten Types
Type	                Bedeutung
feat	                Neues Feature
fix	                    Bugfix
refactor	            Code geändert, aber kein neues Feature
docs	                Nur Dokumentation
chore	                Setup, tooling, config
ci	                    CI/CD Änderungen
infra	                Terraform / Infrastruktur
test	                Tests hinzugefügt


🎯 Beispiel für dein Projekt

Erstes Commit war:

"feat(api): initial Flask job API implementation"

Später:

"feat(docker): add Dockerfile for Flask application"
"infra(network): create VPC and security groups"
"ci(deploy): add GitHub Actions workflow"


So sieht das in Bewerbungen richtig gut aus.
